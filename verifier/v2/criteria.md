# Verifier v1 — критерии приёмки промта доработки SNOW RUSH 3D

Промт (файл `/mnt/agents/output/Промт_доработки_SNOW_RUSH_3D.md`) обязан:

1. Покрывать ВСЕ 14 пунктов пользователя, каждый — отдельной секцией с номером и заголовком:
   1) исследования+скиллы+плейтесты; 2) UI-аудит и удаление фейкового переключателя графики;
   3) переработка экономики на основе исследований; 4) улучшение 3D-моделей;
   5) анимации (полёт, ветер, потоки воздуха, нитро); 6) минимум 5 карт;
   7) исправление «кривого мира» (висячие трамплины, невидимые камни); 8) разворот пингвина;
   9) кривой запуск с рогатки; 10) визуальная эволюция саней/рогатки при апгрейде;
   11) динамика/экшен; 12) качественные разнообразные карты (спуски/подъёмы/повороты);
   13) самостоятельный поиск и исправление багов плейтестами; 14) собственные улучшения каждого пункта.
2. Содержать рабочий процесс: plan.md, поиск/установка скиллов и плагинов, плейтесты между этапами, фиксация результатов.
3. Содержать для каждой секции измеримые критерии приёмки (Definition of Done).
4. Содержать контекст проекта (пути, ветки, существующие документы), чтобы промт был самодостаточным.
5. Быть на русском языке, структурированным (заголовки, нумерация), без противоречий с ТЗ пользователя.
6. Объём — подробный: ≥ 600 слов.

Автопроверка: `check.py` ищет обязательные маркеры по каждому пункту и структурные элементы.
