# SNOW RUSH 3D — Спека большой волны качества

Синтез: 3 исследования (game feel, three.js рендер, дизайн трасс) + видео-аудит текущей версии.
Цель: убрать «сырость» — настоящие 3D-модели, живой рельеф, сочная динамика, кинематографичная камера.

## Диагноз (аудит, что не так сейчас)

1. **Мир плоский и прямой**: не читается уклон, нет волн/роллеров, трасса уходит прямо вперёд, нет S-связок и виражей. Стартовая площадка — плоская поляна, а не вершина спуска.
2. **Модели-примитивы**: пингвин — тёмный комок из сфер, рогатка — два цилиндра, пропсы — конусы/икосаэдры. Потолок процедурного подхода достигнут.
3. **Анимаций почти нет**: пингвин статично сидит, нет крена/приседаний/взмахов; краш — мгновенная остановка без кувырка; запуск без anticipation.
4. **Динамика деревянная**: руль — мгновенное смещение без инерции и сноса; нет FOV-кика, камера прибита; скорость не ощущается (нет speed lines, ветра, микрошума).
5. **Монеты висят в воздухе рядами**, не привязаны к рельефу/баллистике.
6. **Краш необидный в плохом смысле**: стоп-кадр → результаты. Нет hit-stop, slow-mo, кувырка, снежного взрыва.
7. **Меню**: заголовок перекрывает героя; нет сцены-витрины (пингвин + тюбинг + рогатка крупно).
8. **Нет постобработки**: плоский свет, нет bloom/виньетки, тени статичны и шумят при движении.

### W2. Трасса и мир (убить «плоско и прямо»)
По спеке из исследования дизайна:
- **Профиль**: средний уклон 12–18° (секции-бурсты 20–25°, техничные 6–10°), роллеры = сумма 2–3 синусоид (λ 40–80м, амплитуда 2–5м), крупные дропы 8–15м раз в 150–300м. Никогда не ровно >100м.
- **План трассы**: ритм «прямая 60–120м → S-связка 2–3 поворота → выпрямление с событием»; поворот открывается на выходе; виражи (banking 20–35°) на быстрых секциях; ширина 14–20м, сужения-события 6–9м с монетным «хвостом», арены 30–40м под прыжковые серии.
- **Видимость**: следующее решение видно ≥2.5с (90–115м); за гребнем роллера — маркер направления (флаги/монеты).
- **Трамплины**: разбег ≥40м, никогда сразу за поворотом; посадка на склон, совпадающий с углом падения; дуга монет по баллистике.
- **Плотность**: 0–80м пусто (разгон); далее интервал lerp(70→28м) с волной ±30%; safe zone каждые 150–250м (3–6с, монетная змейка/зрелище); кульминация в последних 15% (серия трамплинов + сужение + финишные ворота).
- **Края**: контрастные боковые маркеры с периодом 8–15м (оптический поток = ощущение скорости).
- **Биомные мега-фичи** (силуэт за 1 взгляд):
  - valley: гигантские ели + хижина + подъёмник-пилоны с тросом;
  - canyon: стены-гиганты по краям трассы + естественные арки над трассой;
  - aurora: шейдер-аврора в небе + ледяные монолиты/айсберги;
  - caves: арки/своды над трассой (туннельные секции), светящиеся кристаллы, факелы;
  - volcano: лавовые потоки по краям (emissive), чёрные скалы, гейзеры-трамплины, пепел в воздухе.
- Монеты: паттерны (дуга над трамплином, линия по дну ложбины, змейка в safe zone, хвост-указатель сужения), посадка строго на рельеф.

### W3. Динамика и управление
- **Боковая физика**: латеральная скорость с нарастанием (steering curve, ease-in), grip/снос: карв-зона при удержании наклона (+скорость), на большой скорости руль ужимается; air control лёгкий.
- **Прыжки**: input buffering 100–150мс, coyote 100мс; anticipation-приседание 60–100мс перед вылетом; чистое приземление (угол к склону <30°) = мини-буст, плохое — потеря скорости, перпендикуляр — краш.
- **Буст**: резкий FOV-kick (easeOut 0.3с), камера назад, пламя+трейл (есть), звук.
- **Краш**: hit-stop 60–100мс → slow-mo 0.25 на ~700мс → кувырок 2–4с с отскоками (пролёт ∝ скорости, 50–100м) + снежный взрыв + басовый удар + heavy-шейк → результаты. Near-miss → микро-бонус скорости (петля риск→скорость).
- **Скорость-ощущение**: FOV 60→70–75 на максимуме (damp λ≈3/с), микрошейк >70% скорости, speed lines по краям, ветер volume+pitch по скорости.

### W4. Анимации
- Пингвин (GLB, статичные меши — анимируем узлы): крен в повороте (roll до 30–45°), приседание-anticipation, поза полёта (ласты/крылья — наклон корпуса), squash&stretch 0.7–1.3 на приземлении (recovery ~0.2с), wobble тюбинга (spring-damper после неровностей), idle-озиралка в меню/aim, кувырок при краше.
- Тюбинг: наклон по склону + roll в повороте, сплющивание на приземлении.
- Запуск: натяжение жгутов с прогрессом, откид назад (anticipation), выстрел с выносом камеры.
- Сундук: крышка открывается (узел Chest_Top).
- Пропсы: флаги/гирлянды — волна на ветру (вершинный шейдер или покадровый поворот), факелы/лава — мерцание emissive.

### W5. Камера
- Damp-follow λ≈4–5/с + look-ahead ∝ скорости (вниз по склону + латерально в сторону руления).
- Roll камеры до 10–15° ∝ латеральной скорости.
- Trauma-шейк: shake=trauma², decay ~2/с, только ротационный, ~20Гц Perlin; тиры light (монетка) / medium (приземление) / heavy (краш); уважать reducedMotion.
- В полёте — rotation damping ↓ (камера держит ориентацию, пингвин кувыркается).

### W6. Рендер-стек (по исследованию)
- Renderer: `antialias:false`, DPR ≤2, ACES exposure 1.15, PCF shadows (r182 soft), composer: RenderPass(HalfFloat, samples:4) → UnrealBloom(0.45/0.35/0.88) → SpeedPass (виньетка+speed lines+радиальный blur, ∝ скорости) → OutputPass.
- Небо: скайдоум-шейдер на биом (градиент+солнце/луна+звёзды; аврора-шторы в aurora), PMREM fromScene → scene.environment (5 запечённых), fog = цвет горизонта (лерп при смене карты, мутация без пересоздания).
- Тени: 1 directional, фрустум ±25м следует за игроком, **texel snapping**, bias -0.0001, normalBias 0.02, map 2048.
- Снег: sparkle через onBeforeCompile (+customProgramCacheKey), лёд — low roughness + envMapIntensity>1.
- Снегопад: Points-шейдер ~3k частиц, объём перед камерой (сейчас CPU-частицы — перевести/донастроить).
- Emissive-кюи (лава, кристаллы, аврора, факелы) с emissiveIntensity ≥2 → бесплатное свечение через bloom.
- Бюджет: ≤150 draw calls (инстансинг пропсов!), ≤400k трис, 1 теневой пасс, ≤5 fullscreen пассов.

### W7. Звук и фидбек наград
- Ветер: сгенерировать whoosh-луп, volume+pitch по скорости (playbackRate 0.8–1.4).
- Монеты: pitch-лесенка (серия <1с, pitch=1+combo/100, кап 1.15).
- Подбор: easeOutBack поп 200мс + всплеск частиц + магнит монет (радиус 2м, 5м в серии).
- Результаты: count-up ~2с, NEW BEST с овершутом, конфетти (свои частицы, без либ).
- Краш: басовый whomp + снежный взрыв; UI: рестарт в 1 тап.

### W8. Меню-витрина
- Сцена: пингвин крупно на тюбинге рядом с рогаткой, медленная орбита камеры, idle-анимации; заголовок компактнее, не закрывает героя.

## Критерии приёмки (добавить в verifier/v1/criteria.md)
- track-profile: валидатор рельефа (роллеры/дропы/S-связки присутствуют: дисперсия уклона и кривизны выше порога; нет прямой >120м; нет ровного участка >100м).
- landing-check: каждый трамплин имеет посадочный склон в ±10° от угла траектории.
- budget: draw calls ≤150, tris ≤400k на всех биомах (пробник через диагностику).
- video-audit: субъективный проход оркестратора по кадрам.
