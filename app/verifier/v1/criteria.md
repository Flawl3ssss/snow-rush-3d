# Verifier v1 — критерии приёмки доработки SNOW RUSH 3D (по промту)

Источник: `/mnt/agents/output/Промт_доработки_SNOW_RUSH_3D.md`. Проверки — автоматические, где возможно; скриншот-аудиты фиксируются файлами.

1. **econ-sim**: headless-симуляция прогрессии — каждая карта открывает следующую не раньше 15-го заезда, медиана 15–25; сессия из 10 заездов даёт прогресс без «стены». Скрипт `scripts/sim-economy.ts`, лог в verifier/runs.
2. **economy-doc**: `docs/ECONOMY.md` существует, содержит кривые, sources/sinks, расчёт темпа по картам.
3. **no-graphics-toggle**: в настройках нет переключателя качества графики (grep по src/ui).
4. **five-maps**: ≥5 карт в конфиге, бот проходит все до финиша (smoke-run по каждой карте).
5. **world-validator**: скрипт-валидатор мира зелёный на всех картах (контакт с землёй, коллизия=видимый меш).
6. **penguin-orientation**: код фазы run — пингвин спиной к камере; есть анимация разворота при запуске.
7. **upgrade-visual-tiers**: визуальные тиры саней/рогатки привязаны к уровням апгрейдов (код + конфиг).
8. **build**: `npm run build` зелёный.
9. **smoke**: `scripts/smoke-run.ts` PASS.
10. **ui-audit**: скриншоты экранов × 3 viewport без переполнений (playwright-аудит, отчёт).
11. **animations**: присутствуют системы анимаций полёта/ветра/нитро (grep/код-ревью + кадры).
12. **playtests**: журналы плейтестов в /mnt/agents/output/playtests/ после каждого этапа.
